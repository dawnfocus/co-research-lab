# Experiments

Each experiment lives in `E###-short-name/README.md`. Use [`_template/`](_template/) to create a record; `_template` is not a real experiment ID.

Assign an ID when an experiment becomes a concrete plan, not for every exploratory command. Never reuse an ID. Keep bulky outputs in `storage/runs/E###-short-name/` and record stable artifact locators, hashes, or manifests in the experiment record.
